渡劫code 发布记：打开网页就能写代码的云端 IDE

2026-10-20发布

渡劫code 的第一个公开版本，今天上线。它把对话式编程、Monaco 编辑器、虚拟 Shell 与远程执行后端融为一体——打开网页即用，无需安装任何环境。

它是什么

一个跑在 Cloudflare 边缘网络上的云端开发环境：

  • AI 对话式编程：自然语言描述需求，流式生成代码，SSE 实时推送
  • Monaco 编辑器：VS Code 同款内核，语法高亮、多标签、虚拟文件系统
  • 虚拟 Shell：浏览器内模拟 ls/cat/echo/cd 等命令，即时反馈
  • 远程执行后端：注册后端节点，通过 WebSocket 分发任务到任意机器执行
  • 多用户隔离：账号体系 + 令牌鉴权，数据按账号隔离

技术栈

层选型
前端Vite + React + MUI + Tailwind CSS
边缘运行时Cloudflare Workers（Hono 路由）
存储D1（SQLite）+ KV + R2
实时通道Durable Objects WebSocket
CI/CDGitHub Actions + Wrangler + Pages

立即体验

主域直达，国内外均可访问：

https://gjsvip.github.io/

本地一行命令启动开发：

git clone https://github.com/gjsvip/dujiecode.git
cd dujiecode
npm install
npm run dev

关于名字

「渡劫」——修炼度过天劫，方能更上一层。每一次开发，都像一次渡劫般顺畅，这是这个名字的由来。

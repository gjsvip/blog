域名与 DNS

全部域名收拢在 520691.xyz 之下，三条 CNAME 记录全部走 Cloudflare 代理（小云朵），自动签发 TLS：

www         CNAME   gjsvip-homepage.pages.dev   ✅ proxied
blog        CNAME   gjsvip-blog.pages.dev      ✅ proxied
dujiecone   CNAME   dujiecode.dujie.workers.dev ✅ proxied

注意：早期主机名 dujie_cone 带下划线，严格 TLS 客户端（Python/Go）会因通配证书不匹配下划线而握手失败。已更名为无下划线的 dujiecone.520691.xyz，彻底规避该问题。

工作流拆分

deploy.yml 负责部署，mirror-to-gitee.yml 负责镜像，互不阻塞：

push to main
 ├─ deploy.yml
 │   ├─ build & test（tsc + vitest）
 │   ├─ D1 幂等初始化
 │   ├─ wrangler deploy → Cloudflare Workers
 │   ├─ wrangler pages deploy → Cloudflare Pages
 │   └─ peaceiris/actions-gh-pages → gh-pages 分支
 └─ mirror-to-gitee.yml
     ├─ git push --force gitee main:main
     └─ git push origin/gh-pages → gitee gh-pages（Gitee Pages 源）

踩坑记录

1. Workers 域名绑定：workers/domains API 全线 10405

对所有令牌类型 POST /accounts/{id}/workers/domains 均返回 10405 Method not allowed for this authentication scheme。最终解法是走 zone 级 routes API：POST /zones/{zone_id}/workers/routes，body 为 {pattern, script}，配合 Global API Key 一次成功。

2. 令牌权限的三级体系

凭证类型能力
Account API Token（cfat_）账号端点可用，Zone DNS / Workers domains 全部拒绝
User API Token（cfut_）DNS 可读，POST 写仍 10000（权限只选到 Read）
Global API Key全端点通吃，唯一能写 DNS 的凭证

3. wrangler Pages 部署账号解析陷阱

Pages 部署报 AuthenticationError，真凶不是全局配置，而是 node_modules/.cache/wrangler/pages.json 缓存了旧账号 ID（getCacheFolder 会向上查找 node_modules）。删掉它和 ~/.config/.wrangler/wrangler-account.json 即恢复。

4. gh-pages 推送 403

GitHub Actions 默认 permissions: contents: read，GITHUB_TOKEN 无权推分支。改为 contents: write 后 peaceiris 一次通过。

5. Gitee 拒绝 mirror 推送

deny updating a hidden ref——改为显式 refspec 保活推送：git push --force gitee main:main 加 refs/remotes/origin/gh-pages:refs/heads/gh-pages。

6. 令牌明文进 Git 被 push protection 拦截

GitHub 的 secret scanning（GH013）会拦截 CF 令牌明文。文档中的令牌一律占位符化（cfat_xxx...），真实值只进 Secrets。

国内外可达性

  • dujiecone.520691.xyz 由 Workers 承载，边缘直服，不做地域跳转
  • Gitee Pages 作为国内加速镜像（需在 Gitee 网页端开启 Pages 服务，选 gh-pages 分支）
  • 全站 9 个 URL 实测 200，Cloudflare 自动 TLS，无需手动签证书

收录（SEO）

  • robots.txt + sitemap.xml 覆盖全部域名与文章
  • 通过 IndexNow 协议主动推送（key 文件托管于各站根路径，7/7 主机验证通过）
  • 结构化数据（JSON-LD Blog / SoftwareApplication）已内嵌页面

小结

三端同步的核心是「职责分离」：GitHub Actions 管部署，Gitee 只做代码与 Pages 镜像，Cloudflare 管边缘运行时。一次推送，全链路生效——剩下的，交给自动化。

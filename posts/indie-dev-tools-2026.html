2026 独立开发者工具栈：从建站到支付的零成本清单

🌊 渡劫 · gjsvip 📅 2026-10-21 📂 工具
🧰

常有人问：独立开发是不是很烧钱？我的答案是一年下来云账单 0 元（方法见 额度榨干指南），工具链全部免费或近免费。这篇把栈里的每一项摊开——场景、首选、备选、成本、为什么。不整活，只放真实在用的，链接全部公开可查。

建站与部署

场景首选备选
静态站全球分发Cloudflare Pages（不限带宽）GitHub Pages / Netlify
国内可达镜像Gitee PagesCF Pages + 入口提示
API / 全栈后端Cloudflare Workers + HonoVercel / Netlify Functions
域名解析DNSPod（国内）/ Cloudflare（国际）Namesilo
域名注册Cloudflare Registrar（成本价）/ 腾讯云Namesilo

入口都是公开域名：pages.cloudflare.com、pages.github.com、gitee.com、vercel.com、netlify.com、dnspod.cloud.tencent.com、dash.cloudflare.com。域名是全年最大固定支出（.xyz 首年常驻个位数到十几元人民币），服务器成本为 0 的秘密全在免费额度分层——哪类流量走哪个产品，上一篇刚拆过。

前后端与数据

  • 前端：Vite + React + TypeScript；样式 Tailwind CSS（tailwindcss.com）与 MUI（mui.com）按项目混用；代码编辑器 Monaco（microsoft.github.io/monaco-editor）——渡劫code 的编辑区就是它
  • 边缘数据：Cloudflare D1 / KV / R2 / Durable Objects，选型逻辑见 Workers 全栈实践
  • 传统后端备选：Supabase（supabase.com，免费档含 Postgres + Auth）、Neon（neon.tech，免费 Serverless Postgres）、Upstash（upstash.com，免费 Redis）——需要关系型或缓存时，从这三家里挑
  • ORM：Drizzle（orm.drizzle.team）——SQLite 优先项目的类型安全首选，和 D1 是绝配

选型原则只有一条：读写模型先想清楚，再选存储。读多写少上 D1，热配置上 KV，大对象上 R2——反过来用，免费额度也救不了你。

邮件与通知

  • Resend（resend.com）：免费档每月 3,000 封，API 优先，Workers 里 fetch 直发——评论回复通知就靠它
  • MailChannels（mailchannels.com）：Workers 生态原生，免费档给开发用，适合事务邮件
  • 企业微信 / 钉钉机器人：监控告警推送，个人开发者的「短信平替」——UptimeRobot 的 webhook 直接对接

自建评论系统的邮件回复通知（见 评论系统实战）走的就是这条路：读者留邮箱 → Worker 调 Resend → 回复上线发信。整套零固定成本，发多少付多少。

支付与变现

国内个人开发者的现实路径，和教程里的 Stripe 故事差距很大。务实排序：

方式门槛适合
爱发电 afdian.com个人实名赞助 / 会员 / 早期用户
面包多 mbd.pub个人实名卖软件 Key / 模板 / 资料
Gumroad gumroad.com邮箱即可数字商品出海
Lemon Squeezy / PaddleMoR 模式，免海外主体SaaS 订阅（有抽成）
Stripe需海外/香港主体有主体之后的终点
微信支付个体户 / 企业执照有执照再考虑

我的用法：爱发电挂赞助和高级功能，面包多卖一次性买断。在没有主体之前，MoR 平台和国内实名平台是仅有的现实选项——别在支付渠道上烧启动资金，那是最贵的学费。

数据与分析

  • Cloudflare Web Analytics（dash.cloudflare.com）：免费、无 cookie、不需要同意弹窗——个人站合规成本最低的分析，没有之一
  • Umami（umami.is）：自托管，Workers 可跑，数据完全自有
  • GoatCounter（goatcounter.com）：非商业用途免费，极简，一屏看完所有指标
  • 百度统计：国内流量参考维度的补充，广告网络略重，按需
  • Google Analytics：功能最强，但 consent 弹窗的合规成本对个人站不划算——我的栈里没有它

分析工具的选择标准不是功能多，是不吓跑读者：一个弹窗联盟能赶走的访客，比它能多分析的维度值钱。

监控与运维

  • UptimeRobot（uptimerobot.com）：50 个监控免费，邮件告警，三端各挂一个，SSL 过期也能盯
  • Better Stack（betterstack.com）：免费档含公开状态页，停机时给用户一个解释入口，比 404 体面
  • Cloudflare Notifications：额度用量、Workers 错误率告警，免费档策略管够
  • 国内测速：ITDog（itdog.cn）、17CE（17ce.com）——验证 Gitee 镜像国内可达性的日常工具，Gitee Pages 的坑靠它们提前发现

内容、AI 与杂项

  • LLM API：DeepSeek、智谱 GLM、Kimi 等按量计费，个人开发月成本几十元量级——渡劫code 的多 provider 适配就是给它们准备的
  • 图床 / 媒体：Cloudflare R2 + Images（出流量免费），备选 SM.MS
  • 图标：Lucide（lucide.dev）、Iconify（iconify.design）
  • CI：GitHub Actions 公开仓库全免费、私有仓库每月 2000 分钟——博客的部署链路白嫖到底
  • 凭据管理：wrangler secret 管 Workers，Gitee/GitHub 令牌只进 Actions Secrets，本地密钥文件一律进 .gitignore

选型三原则

  1. 免费档的边界就是架构的边界——先读额度表再画架构图，顺序反了等于裸奔
  2. 数据自主权优先于功能——评论、分析、用户数据能自持就不外包，迁移成本永远比想象高
  3. 国内可达性当一等公民——三端同步不是炫技，是读者在杭州连不上 GitHub Pages 时的尊严

这套栈的总拥有成本：一个域名加几十块 LLM 费用加 0 元基础设施。算笔总账：

项目月成本说明
域名约 1–2 元（年付摊）.xyz 首年折扣常见
Pages / Workers / D1 / KV / R20 元全在免费档内（见榨干指南）
GitHub Actions / Gitee0 元公开仓库 + 自动镜像
LLM API几十元按量，开发期大头
邮件 / 监控0 元免费档管够
合计几十元/月这就是独立开发的入场券
